# Multimodal hybrid convolutional deep learning for genomic prediction of wheat grain yield

Code and summary results for the manuscript *"Multimodal hybrid convolutional deep learning for genomic
prediction of wheat grain yield: a comparison with kernel regression across two breeding cycles"* (G3, in revision).

The study compares a modular hybrid network (independently pretrained and frozen branches for pedigree, markers and
multispectral data, combined by late fusion) with BLUP, RKHS and a published jointly trained multimodal network (MMDL,
Montesinos-López et al. 2023) in two CIMMYT wheat breeding cycles, under five-fold cross-validation with nested
hyperparameter search.

Code comments and file names are in Spanish; this README maps them to the manuscript.

## Naming

| In the files | In the manuscript |
|---|---|
| `Y21`, `Y22` | Cycles 2020–2021 and 2021–2022 |
| `AO`, `GO` | Scaled eigenvectors of the pedigree (A) and genomic (G) relationship matrices |
| `SNP`, `SNP-OHE` | Allele dosage (0, 1, 2) and one-hot encoding (three classes per locus) |
| `DM6AUC` | **DMT**: 32 temporal multispectral metrics |
| `DM` | Six bands at the last flight |
| `DM6` | Raw bands of all flights (Supplementary Table 1 only) |
| `v6` | **Compact** search space (60 trials) |
| `v7` | **Wide** search space (100 trials) and MMDL |
| `final` | Hybrid reported in the manuscript: DLNN-AO (compact) + 1D-CNN-SNP (wide) + DLNN-DMT (wide), compact fusion block |
| `Hibrido_*` | Hybrid models; `MMDL_Montesinos` is the jointly trained multimodal baseline |

Network weights, Optuna databases and kernel files are regenerated by the scripts.

## Running the full pipeline

Everything runs from the repository root, which must contain the raw data (`Y20-21/`, `Y21-22/`) or the processed
data (`Datos_entrenamiento/`); see "Repository contents" for their availability.

| Step | Script | What it does |
|---|---|---|
| 1 | `python preparar_datos.py .` | Joins markers, pedigree, yield and multispectral data; marker filters; DM, DM6 and DMT; five outer folds stratified by trial |
| 2 | `R1_BLUEs_kernels_v6.ipynb` | BLUEs (lattice design with field column), outlier removal, Cullis heritability, AO, GO and kernels |
| 3 | `R2_referencia_BGLR_v6.ipynb` | Pedigree BLUP, unimodal RKHS and multimodal RKHS |
| 4 | `Rscript R3_referencias_extra.R` | GBLUP, BLUP with DMT, multimodal BLUP, and BLUP and RKHS with A + SNP |
| 5 | `bash todo_v6.sh` | Compact networks: unimodal models, hybrids |
| 6 | `bash todo_v7.sh Y21`, `bash todo_v7.sh Y22` | Wide networks, hybrids and MMDL |
| 7 | `bash lanzar_final.sh Y21`, `bash lanzar_final.sh Y22` | Hybrid reported in the manuscript (uses the branches of steps 5 and 6) |
| 8 | `bash lanzar_dlnn_snp.sh` | DLNN fitted to the SNP input, both search spaces and cycles |
| 9 | `ANIO_V6=<cycle> python predicciones_unimodales_v6.py`, `ANIO_V7=<cycle> python predicciones_unimodales_v7.py` | Line-level predictions of the unimodal networks |
| 10 | `python exportar_optuna.py`, `python contar_parametros.py` | Summary of the Optuna studies and number of parameters |
| 11 | `python tablas_figuras_articulo.py` | Tables and Figure 3 |

`desglose_lineas.py` reports how many evaluated lines lacked each data source (read-only; needs the raw data).

Steps 5–8 restart the Python process after each task to release GPU memory. If interrupted, launch them again:
Optuna resumes the studies and finished tasks are skipped.

## Validation protocol

- Five outer folds stratified by trial, identical for all models (written by `preparar_datos.py`, seed 24591).
- Within each outer training set, a fixed internal 80:20 split (64% and 16% of all lines; seed 24591) is used for
  hyperparameter search and early stopping. Each Optuna trial (TPE sampler, seed 271167, median pruner) is trained in the
  five outer training sets and scored by the mean internal-validation MSE.
- The selected configuration is refitted in each outer training set (80%) for the median of the five optimal epochs and
  evaluated once on the outer test fold.
- Hybrid branches are trained per outer fold. The fusion search uses branches trained on the internal-training lines
  (64%); the final hybrid uses branches trained on the outer training set (80%). Branches are frozen.
- Predictors and the response are standardized with the training lines of each fold.
- BGLR seeds: 345322 + fold.

## Modules

| File | Content |
|---|---|
| `optuna_1dcnn_dlnn.py` | Search spaces of DLNN and 1D-CNN (compact `*_v6`, wide `*_v3`), nested search and final evaluation |
| `Pipeline_1dcnn_dlnn.py` | Training of one network per fold |
| `Pipeline_Multimodal_hibrido.py` | Hybrid: frozen branches, fusion block (`fusion_V6` compact, `fusion_V3` wide), search and permutation importance |
| `mmdl_montesinos.py` | MMDL of Montesinos-López et al. (2023) |
| `correr_todo_v6.py`, `correr_todo_v7.py`, `correr_hibrido_final.py`, `correr_dlnn_snp.py` | Run scripts called by the launchers |
| `funciones.py` | Seeds and optional Telegram notification (environment variables `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`) |

## Software

Python 3.12.3, TensorFlow 2.17, Keras 3.3.2, Optuna 4.7.0, NumPy 1.26.4, pandas 2.2.2, scikit-learn 1.4.2,
SciPy 1.14.1, Matplotlib 3.10.8, joblib 1.4.2, openpyxl. R 4.3.3 with BGLR, lme4 and emmeans.
The networks were trained on one GPU inside the NVIDIA TensorFlow container.
